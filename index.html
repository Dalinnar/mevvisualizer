Click a region to select it, then use the arrow keys to move it (X/Z), H/Y to move it up/down (Y), or Delete to remove it. These edits only affect what's on screen until you save them.

Click a region in the 3D view to select it, assign it as Step or Cap, then save the pair. Repeat for as many Step/Cap pairs as you need. Each pair's repeat count is computed automatically from the LCM of step widths sharing an axis, so differently-sized Steps stay evenly spaced. The shared Stack Count field above acts as a cycle multiplier on top of that.
